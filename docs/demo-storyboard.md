## 장면 7
건강검진표는 구현됐다. 차BTI 부화 연출과 공유 카드는 PT 단계이므로 영상에서는 자막으로만 언급한다.

## 촬영 방법
- 에뮬레이터 2560x1440 가로. Windows 녹화는 Xbox Game Bar(Win+G) 또는 OBS.
- 10배속 시나리오라 실제 녹화 시간은 장면당 30초~1분. 편집에서 잘라 쓴다.
- 자막은 편집 프로그램에서. 내레이션은 선택 (TTS SDK는 준비 중이라 앱 안에서는 안 나옴).
- 심사 자료 익명: 영상에 이름·계정·얼굴이 나오지 않게.
