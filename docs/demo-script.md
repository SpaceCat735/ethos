## 편집 메모
- 급정거 장면은 10배속이면 1초라 5배속 소재(v3)를 쓴다. 필요하면 0.5배 슬로우.
- 소모품 상세 장면은 영상 v3에 없다(리포트 앞면만). PR #26 캡처 ②를 정지 화면으로 넣거나, 로컬에서 `--ei speed 5` 끝 주차 화면에서 카드 터치 장면을 따로 10초 녹화.
- 슬라이드 글꼴은 상업적 이용 가능한 것(예: 프리텐다드, 나눔스퀘어). 배경음악은 저작권 무료 음원, 출처를 영상 설명에 적는다.
- 내레이션을 넣을 경우 TTS 도구의 상업적 이용 약관 확인.
