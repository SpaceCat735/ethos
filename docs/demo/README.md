# 데모 영상 편집 키트

## 제출용: v8 (`ethos_demo_v8.mp4`)

2:47, 2560×1440, 30fps, 무음. 낮 테마. 장면은 0.6초씩 겹쳐 넘어가고(xfade), 글자는 본문 42px·제목 78px(#89). 왼쪽에 짧은 글, 오른쪽에 앱 화면을 놓는 구성(화면 위 자막 없음). 글꼴은 Noto Serif KR(제목)·Noto Sans KR(본문), Windows 기본 설치 글꼴.

장면: 타이틀 → 시동 인사(알) → 주행 중(4배속) → 2주가 차면 부화 → 주차 후 상태 → 소모품 상세(권장값 구분) → 운전 습관이 정비 주기를 정함 → 급정거하면 시무룩 → 정체가 길어지면 답답 → 안전 경고 → 월간 점검표 → 정비 기록·도장 → 내 차 설정 → 정비 기록으로 열리는 꾸미기 → 저장 → 세워 둔 동안(숨쉬기·표정) → 마무리.

- 표정이 바뀌는 장면 세 개는 왼쪽 글 아래에 "앞유리 표정 확대" 창을 같이 둔다.
- 글이 많은 두 장면(소모품 상세, 월간 점검표)은 앱 창 대신 목록 부분만 잘라 약 1.4~1.5배로 보여 준다(`scenes`의 `zoom`). 소모품 장면은 스크롤 전에서 끊어 엔진오일 줄이 보이게 한다.
- 장면 길이는 글을 읽는 시간(글자 수 / 6 + 2초) 이상이 되게 하고, 모자라면 마지막 화면을 멈춰 채운다.
- 화면 아래에 "Pleos Connect 에뮬레이터 화면 · 시나리오 재생으로 촬영"을, 빨리 감은 장면에는 배속을 적는다.

### 다시 만들 때 (`v8/`)

1. release APK를 에뮬레이터(Pleos Connect v2.1.0, 2560×1440)에 설치한다. 첫 실행 차급 패널은 스크립트가 "나중에"로 닫는다.
2. 본편 녹화: `bash v8/record_main.sh v8` → `raw_a.mp4`(demo 시나리오 2배속, 0~174초), `raw_b.mp4`(176~262초: 점검표 → 정비 기록 → 정비 수첩 → 차고 색·휠 → 저장).
3. 표정 장면 녹화: `bash v8/record_faces.sh v8` → `raw_c.mp4`(commute 2배속, 급정거), `raw_d.mp4`(traffic_jam 4배속, 정체).
4. 편집: `FFMPEG=ffmpeg CHROME=chrome node v8/build.js shots` → `v8/ethos_demo_v8.mp4`. 미리보기는 `preview`를 붙인다.

- 녹화 파일(`raw_*.mp4`)과 중간 파일은 저장소에 넣지 않는다.
- 장면별 시작·끝 시각은 `build.js`의 `scenes`에 있다. 다시 녹화하면 타이밍이 조금 달라지므로 장면 모음을 뽑아 확인하고 맞춘다.
- `adb`·`ffmpeg`·`chrome`이 PATH에 없으면 `ADB`·`FFMPEG`·`CHROME` 환경 변수로 위치를 준다. Git Bash에서는 `MSYS_NO_PATHCONV=1`이 필요하다(스크립트에 들어 있음).
- 에뮬레이터 시각이 자정 직후여도 부화 장면이 나온다(#86에서 고침).
